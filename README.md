# Bebek Listesi

Telefonda uygulama gibi çalışan bebek kıyafet ve ihtiyaç listesi. Kurulum gerektirmez, internet olmadan da açılır.

## GitHub Pages'e yükleme

1. GitHub'da yeni bir **public** depo açın (ör. `bebek-listesi`).
2. **Add file → Upload files** ile bu klasördeki tüm dosyaları sürükleyip yükleyin, **Commit changes** deyin.
3. **Settings → Pages** bölümünde *Source: Deploy from a branch*, *Branch: main / (root)* seçip **Save** deyin.
4. 1–2 dakika sonra adres hazır olur: `https://KULLANICIADI.github.io/bebek-listesi/`

## Telefona ekleme

- **Android (Chrome):** Adresi açın → ⋮ menü → **Ana ekrana ekle / Uygulamayı yükle**
- **iPhone (Safari):** Adresi açın → Paylaş → **Ana Ekrana Ekle**

## Bilmeniz gerekenler

- Kayıtlar sadece o telefonda saklanır. Eşinizle paylaşmak ya da telefon değiştirmek için ⚙️ → **Yedeği indir / paylaş**, öbür telefonda **Yedekten yükle**.
- Bir ürünü × ile çıkarabilir, her bölümün altındaki **+ ürün ekle** ile yenisini ekleyebilirsiniz.
- "Gerekli" etiketli ürünler üstteki ilerleme çubuğunda sayılır.
